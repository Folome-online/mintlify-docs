---
title: 'Verifying the Connection'
description: 'If your client shows no tools or you want to rule out a setup problem, two quick curl calls tell you whether the server and your API key are both working.'
---

Testing from the terminal takes your editor or chat client out of the picture. Every call needs OAuth sign-in or an `x-api-key` header; curl uses the header, so please make an account at [openfinance.tech](https://openfinance.tech) to get your keys.

## List the tools

Start by asking the server which tools it offers:

```bash
curl -i https://api.openfinance.tech/agent/mcp \
  -H "x-api-key: open_xxxxx" \
  -H "Accept: application/json, text/event-stream" \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}'
```

A `200 OK` with a JSON-RPC payload listing tools means you are good to go.

## Call a wallet tool

Then call a tool that reads your own account. This confirms that your key and your wallet both work:

```bash
curl -i https://api.openfinance.tech/agent/mcp \
  -H "x-api-key: open_xxxxx" \
  -H "Accept: application/json, text/event-stream" \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","id":2,"method":"tools/call","params":{"name":"get_wallet_addresses","arguments":{}}}'
```

A `401` on either call means the key is missing or invalid.
