---
title: 'Troubleshooting'
description: 'When your agent cannot reach OpenFinance or the tools go missing, the cause is usually one of a few common setup problems, and each one has a quick fix.'
---

Find the message or symptom you are seeing below and open it for the fix. Most problems come down to the key, a client that has not reloaded its config, or sending requests too fast.

<AccordionGroup>
  <Accordion title="401 Unauthorized" icon="lock">
    The request had no valid `x-api-key` header and no OAuth sign-in. Every tool, including market data, needs one or the other. Either you forgot the header, or the key is wrong. Re-copy it from the External AI page and make sure the value starts with `open_`. No key yet? Please make an account at [openfinance.tech](https://openfinance.tech) to get your keys.
  </Accordion>

  <Accordion title="Tools do not appear after editing config" icon="rotate">
    Most clients only read the MCP config on startup. Fully quit and relaunch the app, or use the client's "Reload MCP servers" command.
  </Accordion>

  <Accordion title="Skills do not appear after `npx skills add`" icon="book">
    Run `npx skills list` to confirm the install location. If installed globally, restart your editor. If installed to a project, make sure you opened that project root.
  </Accordion>

  <Accordion title="429 Too Many Requests" icon="gauge-high">
    You hit the rate limit, which is per key. Slow your agent down, then retry.
  </Accordion>
</AccordionGroup>

## Still stuck?

If none of these match, look up the tool you are calling in the [MCP server overview](/mcp/overview), which covers every tool the server offers.
