description: 'Prefer to edit config files yourself? This is the manual way to add OpenFinance to Claude Code, for a single project or for every project you work in.'
---

If you used the [Quick Install](/getting-started/quick-install), you are already set up and can skip this page. Otherwise, pick where the server should live, then add the configuration below.

## Option A, Project-level

Use this when only one project should see OpenFinance.

<Steps>
  <Step title="Navigate to your project">
    `cd` into your project folder.
  </Step>
  <Step title="Create config file">
    Create `.mcp.json` in the project root.
  </Step>
</Steps>

## Option B, Global

Use this to make OpenFinance available in every project.

<Steps>
  <Step title="Edit global config">
    Edit `~/.claude.json` (create it if it does not exist).
  </Step>
</Steps>

## Configuration

Whichever option you chose, paste this block into the file with your key. Please make an account at [openfinance.tech](https://openfinance.tech) to get your keys.

```json
{
  "mcpServers": {
    "openfinance-tech": {
      "type": "http",
      "url": "https://api.openfinance.tech/agent/mcp",
      "headers": {
        "x-api-key": "open_xxxxx"
      }
    }
  }
}
```

<Note>
If `~/.claude.json` already has a `mcpServers` object, add the `"openfinance-tech": { ... }` entry inside it rather than replacing the whole file.
</Note>

Restart Claude Code, and the OpenFinance tools are ready to use.
