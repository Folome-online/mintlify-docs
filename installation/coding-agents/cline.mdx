---
title: 'Cline'
description: 'Give Cline, the AI coding extension for VS Code, live OpenFinance tools so you can check markets and place trades without ever leaving your code editor.'
---

Cline keeps its MCP servers in a settings file that you open from its own panel. Add OpenFinance there with your API key, and the tools show up in your Cline conversations.

<Steps>
  <Step title="Open Cline">
    Open VS Code with the Cline extension installed. Click the **Cline** icon in the sidebar.
  </Step>
  <Step title="Open MCP settings">
    Click the **MCP Servers** button (gear icon) in the Cline panel, then **Configure MCP Servers**.
  </Step>
  <Step title="Add the server">
    Add the OpenFinance server:

    ```json
    {
      "mcpServers": {
        "openfinance-tech": {
          "type": "streamableHttp",
          "url": "https://api.openfinance.tech/agent/mcp",
          "headers": {
            "x-api-key": "open_xxxxx"
          }
        }
      }
    }
    ```

    Replace `open_xxxxx` with your key. Please make an account at [openfinance.tech](https://openfinance.tech) to get your keys.
  </Step>
  <Step title="Enable">
    Save the file. Back in the Cline MCP panel, OpenFinance should appear, toggle it on if needed.
  </Step>
  <Step title="Use it">
    OpenFinance tools are now available in Cline conversations.
  </Step>
</Steps>

<Note>
Cline uses `streamableHttp` as the transport type, not `http`.
</Note>
