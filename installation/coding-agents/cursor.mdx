---
title: 'Cursor'
description: 'Add the OpenFinance MCP server to Cursor from the Command Palette: paste the server URL and API key into MCP settings, reload, and trade from Cursor''s chat.'
---

<Steps>
  <Step title="Open Command Palette">
    Press **Cmd+Shift+P** (Mac) or **Ctrl+Shift+P** (Windows).
  </Step>
  <Step title="Open MCP Settings">
    Type `MCP` and select **Cursor Settings: Open MCP Settings**.
  </Step>
  <Step title="Add the server">
    Add the OpenFinance server inside the `mcpServers` object:

    ```json
    {
      "mcpServers": {
        "openfinance-tech": {
          "type": "http",
          "url": "https://api.openfinance.tech/agent/mcp",
          "headers": {
            "x-api-key": "open_xxxxx"
          }
        }
      }
    }
    ```

    Replace `open_xxxxx` with your key. Please make an account at [openfinance.tech](https://openfinance.tech) to get your keys.
  </Step>
  <Step title="Reload">
    Open the Command Palette again, type `MCP`, and select **Reload MCP Servers**.
  </Step>
  <Step title="Use it">
    OpenFinance tools are now available in Cursor's AI chat.
  </Step>
</Steps>
