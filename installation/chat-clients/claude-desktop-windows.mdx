---
title: 'Claude Desktop (Windows)'
description: 'Connect Claude Desktop on your Windows PC to your OpenFinance account in a few clicks, so Claude can check markets and your wallet from any conversation.'
---

Claude Desktop can reach remote MCP servers in two ways: through its Connectors screen, or through its config file. Option A is quicker and the one we recommend; Option B suits you if you would rather manage the server by hand.

## Option A, custom connector (recommended)

These are the same steps the OpenFinance app shows on its External AI page. No API key is needed: Claude signs in to your OpenFinance account.

<Steps>
  <Step title="Add custom connector">
    In Claude Desktop, go to **Settings** → **Connectors** and click **Add custom connector**.
  </Step>
  <Step title="Configure connector">
    Name it `OpenFinance` and paste the MCP server URL:

    ```text
    https://api.openfinance.tech/agent/mcp
    ```
  </Step>
  <Step title="Connect to OpenFinance">
    Click **Connect** on the OpenFinance connector.
  </Step>
  <Step title="Authorize access">
    When Claude first uses the MCP server, you are sent to OpenFinance. Sign in and click **Authorize** to give Claude access.
  </Step>
  <Step title="Try it out">
    Start a new conversation and ask, for example:

    - "Get the price-implied odds of the Golden State Warriors winning the 2026 NBA playoffs using OpenFinance"
    - "Check my OpenFinance Wallet balance"
  </Step>
</Steps>

Custom connectors are set up once per Claude account, so the same connector also appears on [Claude.ai](/installation/chat-clients/claude-ai-web).

## Option B, edit the config file

Prefer a config file? Add the server to `claude_desktop_config.json` with your API key instead.

<Steps>
  <Step title="Open Developer settings">
    Open Claude Desktop → **Settings** → **Developer**.
  </Step>
  <Step title="Edit config">
    Click **Edit Config**. Find `claude_desktop_config.json` and open it with Notepad or any text editor.
  </Step>
  <Step title="Add the server">
    You will see something like this:

    ```json
    {
      "preferences": {
        "coworkScheduledTasksEnabled": true,
        "sidebarMode": "task"
      }
    }
    ```

    Add a comma after the `preferences` closing brace, then paste the `mcpServers` block:

    ```json
    {
      "preferences": {
        "coworkScheduledTasksEnabled": true,
        "sidebarMode": "task"
      },
      "mcpServers": {
        "openfinance-tech": {
          "type": "http",
          "url": "https://api.openfinance.tech/agent/mcp",
          "headers": {
            "x-api-key": "open_xxxxx"
          }
        }
      }
    }
    ```

    Replace `open_xxxxx` with your key. Please make an account at [openfinance.tech](https://openfinance.tech) to get your keys.
  </Step>
  <Step title="Close Claude fully">
    Closing the window leaves Claude running in the system tray. Right-click the Claude icon in the tray, near the clock, and choose **Quit**.
  </Step>
  <Step title="Reopen and verify">
    Reopen Claude Desktop. Start a new conversation, you should see a hammer icon in the chat input area.
  </Step>
</Steps>

<Warning>
Make sure the app is fully closed, not just minimized.
</Warning>
