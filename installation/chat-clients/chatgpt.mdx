---
title: 'ChatGPT'
description: 'Use OpenFinance inside ChatGPT by adding it as a custom app. It signs in to your OpenFinance account with OAuth, so there is no API key to copy or paste.'
---

ChatGPT supports remote MCP servers through Developer Mode, which you switch on once in its settings. After that, setup is a short form and a sign-in.

<Steps>
  <Step title="Enable Developer Mode">
    Open ChatGPT → **Settings** → **Apps** → **Advanced settings** and turn on **Developer Mode**.
  </Step>
  <Step title="Create the app">
    Click **Create app**.
  </Step>
  <Step title="Fill in the details">
    - **Name**: `OpenFinance`
    - **MCP Server URL**: `https://api.openfinance.tech/agent/mcp`
    - **Authentication**: **OAuth**. Leave OAuth Client ID and OAuth Client Secret blank, then click **Create**.
  </Step>
  <Step title="Sign in and approve">
    When ChatGPT first uses the server you are sent to OpenFinance. Sign in and click **Authorize** on the consent page.
  </Step>
  <Step title="Add it to a chat">
    Type `/openfinance` in the chat input and press Enter to add OpenFinance to the current chat.
  </Step>
</Steps>

<Note>
Custom MCP connectors require a ChatGPT Plus, Pro, Business, or Enterprise plan.
</Note>
