---
title: 'Quick Install'
description: 'The fastest way to get OpenFinance working in Claude Code, from installing the playbooks to adding the server, with no config file to open and edit by hand.'
---

If you are on Claude Code, two commands are all it takes: one installs the skills and one adds the MCP server. Have your API key ready for the second.

## 1. Install the OpenFinance skills

<Tip>
Skills are recommended but optional. They teach the agent how to use the tools well.
</Tip>

```bash
npx skills add openfinance-tech/skills -y
```

## 2. Add the MCP server

Every request needs OAuth sign-in or an `x-api-key` header. Please make an account at [openfinance.tech](https://openfinance.tech) to get your keys, then add the server with your key as a header:

```bash
claude mcp add openfinance-tech \
  --transport http "https://api.openfinance.tech/agent/mcp" \
  --header "x-api-key: open_xxxxx"
```

Restart Claude Code and you are done.
