---
title: 'Installing Skills'
description: 'Give your coding agent the OpenFinance playbooks with a single command, choose whether they live in one project or in all of them, and check they loaded.'
---

Skills are SKILL.md-format playbooks that auto-load into your editor when relevant, so your agent knows how to quote, size and place trades on OpenFinance. They work across Claude Code, Cursor, Codex CLI, Gemini CLI, Windsurf, and most modern coding agents.

## One command (auto-detects your editor)

```bash
npx skills add openfinance-tech/skills -y
```

The `skills` CLI detects which editors you have installed and places the SKILL.md files in the right config directories (`.claude/skills/`, `.cursor/`, etc.). The `-y` flag skips the interactive prompt.

## Project-scoped install

Run the command from inside a project to install into that project only:

```bash
cd ~/code/my-trading-bot
npx skills add openfinance-tech/skills -y
```

This creates one folder per skill under `.claude/skills/`, for example `.claude/skills/openfin-hyperliquid/` (and equivalents for other agents), inside the project. Commit the folder to git so your team gets the same playbooks.

## Global install

To make the skills available everywhere instead, add `--global`:

```bash
npx skills add openfinance-tech/skills -y --global
```

This installs to `~/.claude/skills/`, so the skills are available in every project.

## Verify

Whichever way you installed, check what landed:

```bash
npx skills list
```

You should see the OpenFinance skills, such as `openfin-setup` and `openfin-hyperliquid`, in the output. In Claude Code, type `/` and the skill commands will appear in the slash-command menu.

<Note>
Skills installed via `npx skills add` only apply to local editors. They do not apply to Claude.ai web or ChatGPT.
</Note>
