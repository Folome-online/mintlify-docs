## Do I need an API key?

Every OpenFinance MCP request needs OAuth sign-in or an `x-api-key` header, including market data, prices, funding rates, order books and trade previews. There is no keyless tier.

Clients that support OAuth, such as Claude.ai and ChatGPT custom connectors, can sign in to your OpenFinance account instead: add the server URL with no header and approve the consent page when it opens.

Please make an account at [openfinance.tech](https://openfinance.tech) to get your keys. Keys are free to create.

## Get an API Key

<Steps>
  <Step title="Make an account">
    Sign up or sign in at [openfinance.tech](https://openfinance.tech). Your embedded wallet is created at the same time.
  </Step>
  <Step title="Open External AI">
    Open **External AI** in the sidebar (or **Settings → API Keys**).
  </Step>
  <Step title="Create the key">
    Click **Create Key**, give it a name, and copy the value (it starts with `open_`).
  </Step>
</Steps>

<Warning>
**Treat your API key like a password.** It carries the same permissions as your account, including the ability to build and sign trade transactions on connected wallets. Do not commit it to git or paste it into shared chats.
</Warning>

## How the key is used

The key is passed as `x-api-key: open_xxxxx` in every editor or chat-client config. Requests with neither a key nor an OAuth sign-in return `401 Unauthorized`.
