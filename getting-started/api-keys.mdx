Before you connect a coding agent or chat client, it helps to know how OpenFinance recognises it. The short version: your client either signs in with OAuth or sends your key, and the key costs nothing.

## Do I need an API key?

Every OpenFinance MCP request needs OAuth sign-in or an `x-api-key` header, including market data, prices, funding rates, order books and trade previews. There is no keyless tier.

Clients that support OAuth, such as Claude.ai and ChatGPT custom connectors, can sign in to your OpenFinance account instead: add the server URL with no header and approve the consent page when it opens.

Please make an account at [openfinance.tech](https://openfinance.tech) to get your keys.

## Get an API Key

If your client uses a key, here is where to find yours:

<Steps>
  <Step title="Make an account">
    Sign up or sign in at [openfinance.tech](https://openfinance.tech). Your embedded wallet is created at the same time.
  </Step>
  <Step title="Open External AI">
    Open **External AI** in the sidebar.
  </Step>
  <Step title="Copy the key">
    Your key is created for you when you first sign in, one per account. In the **Connect OpenFinance to your AI** card, click the copy button next to **API key**. The value starts with `open_`.
  </Step>
</Steps>

<Warning>
**Treat your API key like a password.** It carries the same permissions as your account, including placing trades and sending funds from your wallet. Do not commit it to git or paste it into shared chats.
</Warning>

## How the key is used

The key is passed as `x-api-key: open_xxxxx` in every editor or chat-client config. Requests with neither a key nor an OAuth sign-in return `401 Unauthorized`.
